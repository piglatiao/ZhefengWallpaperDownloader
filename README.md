# 哲风壁纸下载器

> [Windows] [本地网页] [人工选择] [每日免费额度] [非爬虫]

一个面向个人使用的本地网页交互式壁纸下载工具。

## ✨ 项目定位

本项目是一个“用户选择、按需下载”的辅助工具：打开本地页面后，由使用者选择设备、分类和具体壁纸，再通过哲风壁纸站点正常提供的免费额度完成下载。

**它不是爬虫。** 程序不会后台定时运行、自动遍历全站或批量抓取未选择的内容，也不提供伪造额度、绕过付费限制或无限下载功能。

## 📦 已打包版本

如果项目目录中已有打包文件，直接运行：

```text
dist_single\get_wallpapers.exe
```

可以双击运行，也可以在 PowerShell 中执行：

```powershell
.\dist_single\get_wallpapers.exe
```

程序启动后会自动打开本地网页。如果浏览器没有自动打开，请复制控制台显示的 `http://127.0.0.1:端口/` 地址，在浏览器中访问。

### 基本操作

1. 选择“电脑”或“手机”。
2. 选择壁纸分类。
3. 点击缩略图选择壁纸，可跨页多选。
4. 点击“下载所选”。
5. 在下载进度面板查看结果。

默认使用无头浏览器下载，不会弹出额外窗口。勾选页面中的“可见窗口”后，可以查看下载任务使用的浏览器窗口。

下载完成后，文件会保存在程序当前工作目录下，目录名称类似：

```text
哲风壁纸_电脑_分类名称
哲风壁纸_手机_分类名称
```

使用完成后，请回到程序控制台按 `Ctrl+C` 退出。

## 🛠️ 使用 PS1 脚本

项目提供 `run_or_build.ps1`，可以自动检查环境、运行源码或构建单文件程序。

在项目根目录打开 PowerShell，执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\run_or_build.ps1
```

脚本会检查或准备以下内容：

- Python 3.10 或更高版本
- Python 虚拟环境 `.venv`
- `pycryptodome`
- `websocket-client`
- PyInstaller
- 内置 Chromium 浏览器

随后选择操作：

```text
1. 直接运行源码
2. 构建单文件 exe
Q. 退出
```

选择 `2` 构建完成后，程序位于：

```text
dist_single\get_wallpapers.exe
```

首次运行脚本时需要联网下载 Python 依赖和 Chromium。脚本要求 PowerShell 5.1 或更高版本，并适用于 Windows 环境。

## 🌐 代理设置

默认使用直连网络。如需代理，请在启动程序前设置 `HAO_PROXY`：

```powershell
$env:HAO_PROXY = 'http://127.0.0.1:7897'
.\dist_single\get_wallpapers.exe
```

运行源码或执行 PS1 脚本时同样适用。当前支持填写 HTTP 或 HTTPS 代理地址，例如：

```text
http://127.0.0.1:7897
https://127.0.0.1:7897
```

不需要代理时，不要设置 `HAO_PROXY`，或重新打开一个未设置该变量的 PowerShell 窗口。

## ⚠️ 常见情况

### 分类或缩略图加载失败

请检查网络连接、代理地址和站点是否可以正常访问。使用代理时，确认代理程序正在运行且端口正确。

### 提示当日配额已用完

这是站点额度限制，不是程序故障。请等待次日额度重置，并避免重复尝试。

### 没有自动打开网页

保持控制台窗口打开，复制其中显示的本地地址，在 Chrome、Edge 等浏览器中手动打开。

### 源码运行时找不到浏览器

程序会优先查找项目内置 Chromium，也会查找 Chrome 和 Edge。仍然找不到时，可以设置 `CHROME_BIN`：

```powershell
$env:CHROME_BIN = 'C:\Program Files\Google\Chrome\Application\chrome.exe'
python .\get_wallpapers.py
```

### 下载过程中出现单张失败

网络波动、站点限制或页面验证失败都可能导致单张下载失败。进度面板会记录失败信息，可以稍后重新选择失败项尝试。
