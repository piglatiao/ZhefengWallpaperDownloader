## 修复 WebSocketConnectionClosedException 崩溃（CDP 连接健壮性）
- 现象：用户运行报错 `WebSocketConnectionClosedException: Connection to remote host was lost.`，调用链 `run_download_job → get_one → c.pump()`（line 409），导致整个下载线程崩溃、后续壁纸全部作废。
- 根因：`CDP` 类的 `pump()` 与 `send()` 只捕获 `WebSocketTimeoutException`，未捕获 `WebSocketConnectionClosedException`；标签页/浏览器调试连接被对端关闭时异常冒泡。`send()` 还未设超时，会一直阻塞到 180s 才抛 timeout。
- 修复（`get_wallpapers.py`）：
  - `CDP.__init__` 加 `s.closed=False` 标记。
  - `pump()` 增 `except WebSocketConnectionClosedException: s.closed=True; break`（吞掉断线、置标记）。
  - `send()` 加 `settimeout(180)` + `except WebSocketConnectionClosedException: s.closed=True; raise`；超时转 `RuntimeError`。
  - `get_one()` 外层 `try` 增 `except WebSocketConnectionClosedException: return None,'CONN_LOST'`（单张失败，不击垮线程）。
  - `run_download_job` 对 `get_one` 返回值加 `for _ in range(2)` 重试（仅当 `status=='CONN_LOST'`），偶发断线自愈；仍失败则该张 `fail` 并 `continue`，下一张用新标签页继续。
- 验证：py_compile 通过；两项不耗配额测试——① 强制 `Target.closeTarget` 关标签后 `pump()` 置 `closed=True` 且不抛异常、`send()` 抛 `WebSocketConnectionClosedException`；② 端到端 `get_one` 在开标签后立即断连返回 `(None,'CONN_LOST')` PASS。清理测试遗留 7 个孤儿 chrome.exe（确认无 `get_wallpapers.py` 主进程在跑），剩余 0。
